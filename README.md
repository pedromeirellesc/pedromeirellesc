## Projeto em destaque

### [ShowTrack](https://www.showtrack.com.br)

Plataforma que centraliza shows de plataformas de ticketing brasileiras (Sympla, Ingresse, Eventim), com avaliações e setlists para entusiastas de música ao vivo.

- Backend em Clean Architecture e DDD, com a camada de domínio isolada do framework
- Repository Pattern com inversão de dependência e regras de negócio fora dos models
- Transações e tratamento de constraint única para concorrência, com importação idempotente por upsert
- Busca geográfica de shows por raio configurável em PostgreSQL com PostGIS
- Scraping em Python normalizando os dados de cada plataforma para um contrato único de payload
- Scraping agendado em produção com AWS Lambda, Chalice, SQS e EventBridge
- Processamento assíncrono com Redis e Laravel Horizon
- Classificação automática de shows com fila administrativa de aprovação e rejeição
- Frontend em microfrontends React com Module Federation
- Infraestrutura na AWS como código com Terraform e deploy containerizado com Docker
- Testes com PEST, pytest e Vitest em pipeline de CI/CD no GitHub Actions
- Desenvolvimento com Claude Code e Codex aplicando engenharia de contexto, com AGENTS.md por subprojeto, skills versionadas e uso de agentes e sub-agentes
